# Used car price tier classification with data preprocessing and logistic regression pipeline (R) (Group Project)

技術スタック・開発体制 言語：R 使用ライブラリ：dplyr, caret, car, pROC, MASS 開発形態：チーム開発（4名） バージョン管理：ローカル管理 モデル：ロジスティック回帰

開発内容 中古車市場データを用い、車両が価格上位25％に属するかを分類するモデルを構築しました。 単純な回帰分析ではなく、価格を二値分類問題として再定義し、実務的な意思決定に近い形でモデルを設計しました。

苦労したこと 1．モデルの特異性（singularity）問題 初期モデルでは説明変数に「車種(model)」を含めたところ、派生変数として作成した「SUV」特徴量と依存関係が生じ、モデルが特異状態になりました。 → 原因を特定するため変数依存関係を確認し、設計を見直しました。

2．多重共線性問題 説明変数間の相関により推定値が不安定になりました。VIFを用いて共線性を診断し、影響の大きい変数を段階的に除去しました。

3．実データの品質問題 engineSizeの欠損値、mpg・taxの極端な外れ値、カテゴリ不整合、これらによりモデル性能が大きく変動しました。 → 車種カテゴリに基づく補完、ロバストな外れ値処理を実装し、安定化しました。

工夫したこと 1．モデル精度だけでなく「安定性」を重視 2．変数選択を stepAIC で自動化 3．学習／評価データ分離による過学習防止 4．ROC・AUCによる評価導入
